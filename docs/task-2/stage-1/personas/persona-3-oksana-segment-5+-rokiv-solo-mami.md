### Фото та ім'я:&#x20;

Оксана, 34 роки.
{% endstep %}

{% step %}
### Соцдем:

Проживає у Кельні 5 років. Сину 6 років. Соло-мама, працює фултайм. Рівень німецької — B2+.
{% endstep %}

{% step %}
### Ціль:

Знайти перевірених вузьких спеціалістів (україномовного логопеда) та розширити коло знайомих працюючих мам.
{% endstep %}

{% step %}
### Мотивація:

Заощадити особистий ресурс і час, уникнути материнського вигорання, отримати якісний нетворкінг.
{% endstep %}

{% step %}
### Бар'єри:

* **Інформаційні**: флуд, спам і відсутність реальних відгуків у загальних чатах.
* **Психологічні**: не бажає бути «психотерапевтом» для новоприбулих, шукає адаптованих людей.
{% endstep %}

{% step %}
### Образ мислення:

«Мій час коштує дорого. Я не хочу тиждень фільтрувати чати, щоб знайти одного лікаря. Мені потрібен конструктив і люди мого рівня.»
{% endstep %}

{% step %}
### Потреби:

Структурований довідник спеціалістів із бейджами надійності та відгуками. Нетворкінг за спільними інтересами.
{% endstep %}

{% step %}
### Глибинні потреби:

Самореалізація, ефективний тайм-менеджмент, збереження здорового балансу між кар'єрою та сім'єю.
{% endstep %}

{% step %}
### Трансформація:

{% hint style="danger" %}
**ДО**: Витрачає години на перевірку фахівців у групах, відчуває брак якісного дорослого дозвілля.
{% endhint %}

{% hint style="success" %}
**ПІСЛЯ**: В один клік знаходить топ-спеціаліста, відвідує бранчі з амбітними мамами-експатками.
{% endhint %}
{% endstep %}
