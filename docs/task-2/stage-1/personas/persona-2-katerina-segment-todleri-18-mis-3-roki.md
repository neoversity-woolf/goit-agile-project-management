### Фото та ім'я:&#x20;

Катерина, 32 роки.
{% endstep %}

{% step %}
### Соцдем:

Проживає у Кельні 1,5 року. Сину 3 роки. Ходить на інтеграційні курси, чекає на садок (Kita). Рівень німецької — B1.
{% endstep %}

{% step %}
### Ціль:

Знайти компанію однолітків для сина та розібратися з місцевою бюрократією (оформлення в Kita).
{% endstep %}

{% step %}
### Мотивація:

Соціалізувати дитину перед садком, зберегти рідну мову; сформувати коло спілкування з близькими за цінностями сім'ями.
{% endstep %}

{% step %}
### Бар'єри:

* **Фізичні**: мами з чатів живуть на інших кінцях міста (40 хв їзди).
* **Інформаційні**: у Facebook-групах застаріла інформація про черги до садків (за 2022 рік).
{% endstep %}

{% step %}
### Образ мислення:

«Дитині нудно самій, а німецькі діти на майданчику вже мають свої компанії. Я абсолютно гублюся в місцевій бюрократії.»
{% endstep %}

{% step %}
### Потреби:

Радар знайомств із фільтром за точним віком дитини. Покрокові, актуальні гайди щодо бюрократії (Kita, виплати).
{% endstep %}

{% step %}
### Глибинні потреби:

Відчуття контролю над життям, успішна інтеграція дитини в нове суспільство без втрати власної ідентичності.
{% endstep %}

{% step %}
### Трансформація:

{% hint style="danger" %}
**ДО**: Розгублена перед бюрократією, відчуває провину, що дитині нудно без друзів.
{% endhint %}

{% hint style="success" %}
**ПІСЛЯ**: Має чіткий алгоритм дій для садочка, регулярно відвідує локальні playdates із сусідками.
{% endhint %}
{% endstep %}
