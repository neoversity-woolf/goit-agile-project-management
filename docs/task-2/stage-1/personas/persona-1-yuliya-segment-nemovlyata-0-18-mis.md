### Фото та ім'я:&#x20;

Юлія, 25 років

{% step %}
### Соцдем:

Проживає у Берліні 9 місяців. Сину 1.5 року. Чоловік залишився в Україні. Рівень німецької — А1.
{% endstep %}

{% step %}
### Ціль:

Знайти маму-подругу для щоденних прогулянок у радіусі 500 м та дізнатися європейські аналоги ліків.
{% endstep %}

{% step %}
### Мотивація:

Мінімізувати щоденний стрес від самотності та бути повністю впевненою у безпеці й здоров'ї немовляти.
{% endstep %}

{% step %}
### Бар'єри:

* **Психологічні**: страх здатися нав'язливою на вулиці
* **Соціальні**: не довіряє анонімам з інтернету (боїться фейкових профілів)
* **Фізичні**: не знає мови для читання етикеток у магазинах/аптеках
{% endstep %}

{% step %}
### Образ мислення:

«Я відчуваю гостру ізоляцію щовечора. Мені страшно, що я не зможу купити правильну мазь від висипу через мовний бар'єр. Хочу впевненості та спокою.»
{% endstep %}

{% step %}
### Потреби:

Миттєво бачити перевірених мам поруч для спільної кави. Доступ до чіткого словника-маркування медикаментів.
{% endstep %}

{% step %}
### Глибинні потреби:

Потреба в емоційній безпеці, відчутті «своєї зграї» та плеча підтримки у вразливий період материнства.
{% endstep %}

{% step %}

{% hint style="danger" %}
ДО: Тривожна, постійно сидить у токсичних чатах, почувається соціально ізольованою.
{% endhint %}

{% endhint %}
