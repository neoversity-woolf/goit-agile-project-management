# Олена, 28 р., Мюнхен

{% stepper %}
{% step %}
#### Контекст (Context)

У Мюнхені 5 місяців, доньці 8 місяців. Чоловік працює айтівцем з ранку до ночі. День бабака: годування, сон, дві прогулянки наодинці. Спілкуюся тільки з чоловіком ввечері та з мамою по відеозв'язку.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Вчора вийшла в Англійський сад, хотіла знайти когось для компанії, але німецькі мами вже у своїх колах, а заговорити німецькою боюся.

Шукати через Facebook незручно, бо всі живуть на іншому кінці міста.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

Минулого тижня у доньки була температура 38.8 на зуби.

Шукала педіатра зі знанням мови через дописи у Facebook.

Шукала пів дня, панічно боялася переплутати дозування німецького сиропу від жару.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Найгострішу ізоляцію відчула минулих вихідних: чоловік був у відрядженні, а я два дні не чула живої дорослої мови.

Швидка порада потрібна, щоб зняти щоденний страх помилки в чужій країні.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Потреба в побутовій пораді чи контакті лікаря виникає 3-4 рази на тиждень.

Якщо жити так далі, це прямий шлях до післяпологової депресії та виснаження.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Гортаю загальні групи у Facebook.

Найбільше дратує застаріла інформація, сварки в коментарях замість чіткої відповіді та нецільова реклама.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Дуже непокоїть, чи людина з інтернету справді та, за кого себе видає.

Боюся шахраїв, не піду на зустріч з анонімного акаунту без перевірки.
{% endstep %}

{% step %}
#### Бар'єри та вимоги (Barriers)

Пробувала Bumble BFF — там немає матерів з немовлятами в моєму районі, алгоритм показував дівчат за 15 км.

Згодна повторно пройти тест
{% endstep %}
