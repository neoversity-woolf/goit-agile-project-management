# Олена, 28 р., Мюнхен

{% step %}
#### Контекст (Context)

В Німеччині 5 місяців, доньці 8 місяців. День бабака: годування, сон, дві прогулянки з візком наодинці. Спілкуюся лише з чоловіком ввечері та з мамою по відеозв'язку.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Вчора хотіла знайти компанію на сусідньому майданчику, але там усі говорили німецькою і вже були у своїх компаніях. Шукати через групи у Facebook незручно, бо жінки живуть в інших кінцях міста.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

Минулого тижня у доньки була температура на зуби. Шукала педіатра, який розуміє українську, через пости у Facebook. Процес зайняв пів дня, панічно боялася переплутати дозування ліків.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Найгострішу ізоляцію відчула минулих вихідних, коли чоловік працював, а я два дні не мала з ким перекинутися словом. Швидка допомога важлива, щоб не відчувати безпорадності в чужій країні.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Потреба виникає 3-4 рази на тиждень. Якщо проблему не вирішити, мій емоційний стан погіршиться, що вплине на дитину. Зростає ризик депресії.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Шукаю відповіді в загальних чатах. Найбільше дратує тотальний хаос, застаріла інформація, сварки в коментарях і те, що на питання відповідають рекламою.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Перед зустріччю наживо дуже непокоїть, чи це реальна людина і чи вона адекватна. Боюся шахраїв та фейкових профілів, потрібна впевненість у безпеці дитини.
{% endstep %}

{% step %}
#### Бар'єри та вимоги (Barriers)

Скористалася б радаром для спонтанної щоденної прогулянки та довідником, щоб мати під рукою базу лікарів. З радістю подивлюся прототип.
{% endstep %}
