# Наталя, 35 р., Мюнхен

{% stepper %}
{% step %}
#### Контекст (Context)

У Мюнхені 1.5 року, сину 2 роки. Виховую дитину сама, батько дитини в Україні.

День розписаний по хвилинах: підробіток на телефоні, дитина, готування, побут.

Коло спілкування мінімальне, весь час забирає виживання.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Хотіла знайти таку саму маму поруч, щоб діти гралися разом у пісочниці, поки ми розмовляємо.

Завадило те, що я фізично не маю часу їздити на зустрічі кудись далі найближчого скверу біля дому.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

Сину знадобилася довідка для черги в ясла, терміново потрібен був огляд лікаря.

Шукала через співробітницю з курсів, обдзвонювала клініки сама.

Витратила тиждень часу, поки знайшла вільне вікно на прийом.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Найбільший біль — коли мені потрібно піти в Jobcenter або на важливий прийом, а дитину ні з ким залишити навіть на одну годину.

Повна відсутність підстраховки робить мене беззахисною.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Потреба у взаємодопомозі чи терміновій пораді виникає стабільно 1-2 рази на тиждень.

Якщо не буде кому допомогти підмінити на годину, я просто не зможу владнати документи та піти на роботу.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Прошу знайому з іншого району, але їй треба їхати 50 хвилин, це дуже незручно.

У відкритих групах просити про допомогу страшно і соромно.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Дуже суворо ставлюся до безпеки: ніколи не впущу людину і не залишу сина без підтвердження особи та відгуків інших знайомих мам.
{% endstep %}

{% step %}
#### Бар'єри та вимоги (Barriers)

Шукала бебісітерів через німецькі сервіси (Betreut.de), але це дуже дорого для соло-мами, а довіри до незнайомців немає.

Ціково було приймати участь в опитуванні. Згодна пройти його ще раз
{% endstep %}
