# Катерина, 32 р., Кельн

{% stepper %}
{% step %}
#### Контекст (Context)

У Кельні півтора року, сину 3 роки. Ходимо на інтеграційні курси, чекаємо на місце в садку (Kita). Є кілька знайомих з курсів, але вони живуть далеко.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Сину нудно гуляти самому, шукала йому компанію для ігор. Завадило те, що всі знайомі живуть у різних кінцях міста, а їхати 40 хвилин заради прогулянки незручно. Потрібен хтось у пішій доступності.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

Терміново знадобився дитячий стоматолог. Гуглила німецькою, перекладала відгуки, витратила 3 дні, щоб знайти лікаря. В загальних чатах вузьких спеціалістів не радять.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Найбільший біль зараз — бюрократичний глухий кут із чергами до садочка. Немає в кого запитати покроковий алгоритм дій, відчуваю себе безпорадною перед місцевою системою.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Потреба в соціалізації для дитини є щоденною. Якщо не знайти компанію зараз, сину буде дуже складно адаптуватися в німецькомовному садку.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Шукаю інформацію на локальних форумах. Найбільше дратують застарілі дані — люди діляться правилами 2022 року, які давно змінилися.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Був неприємний досвід з іншими додатками — людина намагалася продати мережеву косметику. Боюся прихованих мотивів та комерційного спаму.
{% endstep %}

{% step %}
#### Бар'єри та вимоги (Barriers)

Додаток потрібен для отримання актуальних чеклістів по Kita та пошуку однолітків для сина у радіусі 1 км. Прототип цікавий, поділюся з мамами на курсах.
{% endstep %}
