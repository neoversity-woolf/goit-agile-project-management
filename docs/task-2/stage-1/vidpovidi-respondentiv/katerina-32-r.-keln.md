# Катерина, 32 р., Кельн

{% step %}
#### Контекст (Context)

У Кельні 1.5 року, сину 2.5 роки. Чоловік працює на виробництві.

Вчимо німецьку, гуляємо, стоїмо в черзі на дитячий садок.

Спілкуюся з двома дівчатами з мовних курсів, але вони живуть на іншому березі Рейну.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Син тягнеться до дітей на майданчику, але німецькі малюки грають окремо.

Хотіла знайти когось для спільних ігор поруч, але їздити з пересадками через усе місто щодня нереально.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

Терміново знадобився дитячий стоматолог, син упав і вдарив ясна.

Шукала через перекладач у Google Maps і міських відгуках.

Витратила півтора дня на дзвінки в праксиси німецькою мовою з тремтячим голосом.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Головний біль — це папери на Kita-Gutschein та черги в садок.

Немає в кого запитати свіжий алгоритм, відчуваю глухий кут перед німецькою бюрократією.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Щодня бачу, як син нудьгує без спільних ігор рідною мовою.

Якщо не знайти друзів зараз, малюку буде значно важче адаптуватися в німецькому садку.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Шукаю інформацію на загальних форумах та сайтах міської ради.

Дратують застарілі інструкції: люди копіюють правила 2022 року, які зараз не працюють.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Був неприємний випадок, коли знайома з чату виявилася агенткою мережевого маркетингу і нав'язувала косметику.

Хочу спілкуватися заради дітей, а не продажів.
{% endstep %}

{% step %}
#### Бар'єри та вимоги (Barriers)

Пробувала німецький додаток, але він суто німецькою мовою і не враховує проблем мігранток без знання мови.

Готова пройти опитування повторно
