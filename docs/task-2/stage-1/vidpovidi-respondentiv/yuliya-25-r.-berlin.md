# Юлія, 25 р., Берлін

{% step %}
#### Контекст (Context)

У Берліні 8 місяців, сину 14 місяців. Чоловік залишився в Україні.

Живу сама з малюком, вчу мову онлайн, постійно гуляю парком.

Живого спілкування в місті взагалі немає.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Бачила україномовну маму на майданчику, але посоромилася підійти першою, бо здалося, що буду нав'язуватися.

Зараз ніяк не шукаю компанію — просто намотую кола з візком наодинці.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

У малюка з'явився гострий висип на щоках.

Написала в Telegram-чат «Мами Берліна», щоб дізнатися німецький аналог антигістамінної мазі.

Повідомлення швидко заспамили іншими темами, відповіді так і не отримала.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Ізоляція накочує щовечора, коли дитина засинає і ти залишаєшся сама в чотирьох стінах.

Важливо мати зв'язок зі своїми, щоб отримати підказку щодо базових побутових дрібниць.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Питання виникають майже щодня: від підгузків до вибору термометра.

Якщо не знайду підтримки, просто замкнуся в собі від хронічного стресу.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Читаю величезні чати на 15 тисяч людей у Telegram.

Втомлює суцільний потік флуду, пересилки новин і відсутність нормального пошуку за районами.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Не довіряю порожнім профілям без реальних фото дитини.

Хвилююся за базову безпеку: чи це адекватна жінка, перш ніж призначати прогулянку.
{% endstep %}
