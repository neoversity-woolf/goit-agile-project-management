# Юлія, 25 р., Берлін

{% stepper %}
{% step %}
#### Контекст (Context)

У Берліні 9 місяців, сину 1. 5 року. Чоловік залишився в Україні. Вдень намагаюся вчити мову, багато гуляю з візком. Живого спілкування тут практично немає.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Нещодавно бачила україномовну маму в супермаркеті, але посоромилася підійти. Зараз ніяк не шукаю компанію, бо на місцевих майданчиках усі розбиті по групах, а підходити першою страшно.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

У дитини з'явився висип, потрібно було швидко знайти аналог нашої мазі. Написала в Telegram-чат «Мами Берліна», але повідомлення швидко загубилося серед тисяч інших.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Ізоляцію відчуваю щовечора, коли дитина засинає. Бракує елементарних побутових порад від тих, хто вже пройшов цей шлях, щоб не винаходити велосипед і не платити за помилки.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Потреба в пораді виникає майже щодня. Якщо не знайду коло спілкування, просто замкнуся в собі, а дитина не матиме своєчасної соціалізації.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Telegram-чати на 10-20 тис. людей. Втомлює спам, нескінченний флуд. Знайти маркування ліків чи харчування по пошуку нереально.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Не довіряю анонімним профілям без фотографій. Хочу бачити, що людина має хоч якесь підтвердження особи, перш ніж йти з нею на прогулянку.
{% endstep %}

{% step %}
#### Бар'єри та вимоги (Barriers)

Додаток ідеально підійшов би для пошуку компанії на каву в радіусі 500 метрів прямо зараз. Прототип подивлюся із задоволенням.
{% endstep %}
{% endstepper %}
