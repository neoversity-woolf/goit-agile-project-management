# Тетяна (29 років, Франкфурт, дитина 2 роки)

#### (Контекст): Як давно ви переїхали до Німеччини, у якому місті живете та скільки років вашій дитині?

У Франкфурті (район Борнхайм) живемо вже 1.5 роки. Доньці Анні зараз 2 роки
{% endstep %}

{% step %}
#### (Ситуація (Situation)): Як саме ви зараз шукаєте компанію для щоденних прогулянок із візочком? Чому цей спосіб для вас зручний чи незручний?

Намагаюся моніторити дитячі майданчики, але важко знайти однолітків. Зазвичай там гуляють або зовсім немовлята, або старші німецькі діти. Спосіб неефективний, бо немає фільтрації за віком малюка
{% endstep %}

{% step %}
#### (Дослідження проблеми (Problem) - медицина): Яким чином ви шукали свого педіатра у новому місті?

Знайшла праксис сама поруч із домом, але зараз ми в процесі активного пошуку іншого лікаря. Поточний педіатр при будь-якій застуді одразу виписує сильні антибіотики, а я шукаю спеціаліста з більш сучасним та лояльним підходом
{% endstep %}

{% step %}
#### (Дослідження проблеми (Problem) - біль): Опишіть ситуацію, коли ви востаннє відчували гостру ізоляцію чи брак порад від «своїх» за кордоном? Чому це важливо для вас?

Коли шукала дитячий басейн або розвиваючі гуртки для дворічок українською чи англійською мовою. В інтернеті інформація дуже розмита, а хотілося б почути реальний досвід мам, які вже туди ходили. Дитині критично потрібна соціалізація
{% endstep %}

{% step %}
#### (Наслідки (Consequences)): Як часто протягом тижня ви стикаєтеся із завданнями, де потрібна порада іншої мами поруч? Що станеться, якщо цю проблему не буде вирішено?

Приблизно раз на тиждень, коли виникають питання щодо дитячого дозвілля або вибору товарів. Якщо не вирішити — дитина буде відставати в соціальному розвитку, а я витрачатиму зайві гроші на неперевірені секції
{% endstep %}

{% step %}
#### (Як зараз вирішують (Current Solutions)): Що вас найбільше дратує або втомлює у теперішніх великих Telegram-чатах чи групах Facebook?

Повідомлення летять вгору зі швидкістю світла. Якщо ти не перевіряв телефон дві години через дитину — твій запит про лікаря чи гурток опустився на самісіньке дно, його ніхто не помітив, і доводиться спамити знову
{% endstep %}

{% step %}
#### (Критичність (Urgency)): Яким побоювання щодо безпеки особистих даних у вас виникають, коли ви думаєте про зустріч офлайн із людиною з інтернету?

Я хочу бачити реальні відгуки від людей з реальними профілями, фотографіями та історією в додатку, а не спілкуватися з анонімними нікнеймами "Мяу99" чи ботами
{% endstep %}

{% step %}
#### (Бар'єри та вимоги (Barriers & Criteria)): Якби існував мобільний додаток, який показує верифікованих українських мам у радіусі 500 метрів від вашого дому та базу лікарів — у яких ситуаціях ви б ним скористалися?

Можливість відфільтрувати матусь чітко за віком дитини (2 роки) на карті поруч — це скарб, я б одразу знайшла компанію доньці. Також шукала б там рейтинги педіатрів. Відмовилася б користуватися, якщо додаток стане повністю платним без безкоштовного тріалу
{% endstep %}
