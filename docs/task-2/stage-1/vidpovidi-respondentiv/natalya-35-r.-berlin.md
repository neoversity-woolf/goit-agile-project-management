# Наталя, 35 р., Берлін

{% stepper %}
{% step %}
#### Контекст (Context)

У Берліні 4 роки, доньці 5 років. Працюю фултайм. Спілкуюся з колегами та друзями ще з до-емігрантських часів.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Хотіла знайти компанію для походу в дитячий музей на вихідних. Старі знайомі були зайняті, а шукати нових людей свого соціального рівня та інтересів дуже важко.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

Садочок раптово закрився через страйк, а мені треба було працювати. Терміново шукала няню або маму, яка могла б забрати двох дітей на один день. Знайти перевірену людину за годину неможливо.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Відчуваю брак культурного дозвілля та людей зі схожими інтересами. Хочеться розширити коло знайомих, не перетворюючись на довідкове бюро для новачків.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Потреба виникає рідко, але в екстрених випадках (страйк садка). Якщо проблему не вирішити, зривається робочий день і виникають проблеми на роботі.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Використовую загальні чати. Вони перевантажені, неможливо швидко відфільтрувати корисну інформацію, багато нецільового флуду.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Не хочу витрачати час на токсичних людей або тих, хто постійно скаржиться на життя. Потрібна фільтрація за інтересами та конструктив.
{% endstep %}

{% step %}
#### Бар'єри та вимоги (Barriers)

Використовувала б для пошуку компанії на конкретні події (музей, басейн) та для екстреного пошуку перевіреної няні. Можете надсилати прототип.
{% endstep %}
{% endstepper %}
