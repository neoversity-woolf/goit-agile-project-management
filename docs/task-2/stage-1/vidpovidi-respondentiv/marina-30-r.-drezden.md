# Марина, 30 р., Дрезден

{% stepper %}
{% step %}
#### Контекст (Context)

У Дрездені 1.2 року, доньці 2.8 року. Чоловік працює на складі позмінно.

Донька активна, цілими днями на вулиці, я намагаюся вчити слова до курсів.

Крім сім'ї, контактую лише з продавцями в магазинах.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Хотіла скооперуватися з мамою-сусідкою з нашої вулиці, щоб разом виходити на прогулянки та по черзі дивитися за дітьми.

Проблема в тому, що я навіть не знаю, чи живуть у нашому мікрорайоні українські сім'ї з дітьми такого віку.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

Треба було терміново потрапити до педіатра через підозру на отит.

Не знала, куди бігти, бо наш лікар був у відпустці.

Витратила 4 години на вичитування відгуків у чатах, де половина адрес виявилася неактуальною.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Найважче, коли потрібно вийти до лікаря або в аптеку, а дитина вередує, і немає навіть сусідки, яку можна попросити підстрахувати.

Брак взаємовиручки найсильніше виснажує.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Критичні ситуації, коли потрібна поміч або порада, трапляються щотижня.

Без розв'язання цієї проблеми відчуваю постійну хронічну втому та апатію.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Пишу питання в районний Telegram-чат.

Дратує, що замість відповідей на тему педіатра починаються дискусії про політику чи нецільовий флуд.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Категорично боюся довіряти дитину або зустрічатися наодинці з людьми без реальних підтверджених профілів.
{% endstep %}

{% step %}
#### Бар'єри та вимоги (Barriers)

Шукала тематичні чати в месенджерах, але там усе перетворюється на смітник повідомлень без локальної прив'язки.

Тема вкрай потрібна, кличте.
