# Марина, 30 р., Дрезден

{% stepper %}
{% step %}
#### Контекст (Context)

У Дрездені 1 рік, дитині 2. 5 роки. Вчимо мову, чекаємо на садок. Спілкуюся виключно з родиною.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Хотіла знайти маму-сусідку, щоб по черзі сидіти з дітьми (бейбісіттінг-шеринг). Завадило те, що я просто не знаю, хто з мого або сусіднього під'їзду також має дітей.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

Треба було терміново піти в амбюлаторію (Амт) для оформлення документів. Не було з ким залишити дитину на 2 години, довелося брати з собою і вистояти з істерикою в черзі.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Гостра криза була, коли відчула сильне материнське вигорання. Дитина зі мною 24/7, немає надійного перевіреного контакту поряд для елементарної взаємовиручки.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Раз на місяць виникає критична потреба підмінити одна одну на пару годин. Без цього настає повне виснаження та неможливість вирішувати бюрократичні питання.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Беру дитину з собою скрізь. Просити чужих людей з чату посидіти з малюком абсолютно неможливо і небезпечно.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Категоричний страх залишити дитину з незнайомою людиною. Для бейбісіттінгу необхідне стовідсоткове підтвердження особи та система взаємних відгуків.
{% endstep %}

{% step %}
#### Бар'єри та вимоги (Barriers)

Додаток ідеальний для бейбісіттінг-шерингу в межах мікрорайону, якщо там буде надійна система довіри. Прототип дуже цікавий.
{% endstep %}
{% endstepper %}
