# Анна, 30 р., Варшава

{% step %}
#### Контекст (Context)

Живемо у Варшаві 10 місяців, доньці 1 рік. Чоловік працює допізна. Будні дуже одноманітні: парк, магазини, дім. Спілкуюся тільки з дитиною.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Намагалася знайти компанію через міський чат Варшави. Знайшла дівчину, але її дитині 4 роки — вони бігають, а ми спимо у візку. Незручно, бо немає фільтру за точним віком малюка.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

Потрібен був плановий огляд педіатра. Скролила історію чату 2 години, знайшла контакт, але лікар вже не приймав нових пацієнтів. Витратила купу часу даремно.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Ізоляція накриває, коли хочеться поділитися успіхами дитини, а поруч нікого немає. Можливість знайти маму з дитиною такого ж віку критична для мого емоційного розвантаження.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Потреба виникає 1-2 рази на тиждень. Якщо не вирішити, я просто перестану намагатися знайомитися і залишуся в соціальному вакуумі.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Варшавські чати у Viber/Telegram. Дратує відсутність структурованого каталогу. Контакти лікарів швидко губляться серед сотень нерелевантних повідомлень.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Турбує, чи не буде людина нав'язливою або токсичною. Побоювань щодо даних менше, більше хвилює психологічний комфорт під час зустрічі.
{% endstep %}

{% step %}
#### Бар'єри та вимоги (Barriers)

Використовувала б для пошуку мами саме з однорічною дитиною для спільних прогулянок візками. Показуйте прототип, пораджу сестрі.
{% endstep %}
