# Анна, 30 р., Варшава

{% stepper %}
{% step %}
#### Контекст (Context)

У Гамбурзі 10 місяців, доньці рівно 1 рік. Чоловік працює допізна.

Будні одноманітні: набережна, супермаркет, домашні справи.

Коло спілкування звузилося до дитини та дзвінків батькам.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Пробувала знайомитися через районний чат, але відгукнулася жінка з чотирирічною дитиною — у них активні ігри, а ми спимо у візку.

Незручно домовлятися, коли немає збігу за віком.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

Потрібно було пройти обов'язковий огляд U6 у педіатра.

Шукала лікаря зі знанням англійської чи української за порадами на форумі.

Витратила два дні: виявилося, що контакти з форумів уже не беруть нових пацієнтів через перевантаження.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Найбільше накриває почуття самотності, коли хочеться розділити перші кроки дитини з іншою мамою за чашкою кави.

Без підтримки відчуваю себе відірваною від світу.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Питання виникають 1-2 рази на тиждень.

Якщо проблему не вирішити, я повністю втрачу мотивацію виходити далі власного двору.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Локальні групи у Facebook та чати у Viber.

Дратує те, що інформація губиться за хвилини, немає перевірених списків лікарів із позначками районів.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Боюся потрапити на нав'язливих або токсичних людей, які виливають негатив.

Хочеться спокійного, взаємно поважного спілкування.
{% endstep %}

{% step %}
#### Бар'єри та вимоги (Barriers)

Раніше реєструвалася в локальних групах експатів, але там здебільшого студенти без дітей.

Обов'язково.
{% endstep %}
