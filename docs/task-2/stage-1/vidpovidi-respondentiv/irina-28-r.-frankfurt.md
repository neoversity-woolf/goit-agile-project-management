#### Контекст (Context)

Живемо у Франкфурті 2 роки, сину 4 роки. Намагаюся працювати віддалено на парт-тайм. Спілкуюся переважно з колегами по зуму.
{% endstep %}

{% step %}
#### Ситуація (Situation)

Шукала компанію на сусідньому майданчику. Німецькі діти вже граються своїми компаніями, моєму сину важко влитися через мову. Хотіла знайти україномовних сусідів, але не знаю як.
{% endstep %}

{% step %}
#### Дослідження проблеми (Медицина)

Медичну систему вже більш-менш зрозуміла. Натомість велика проблема з купівлею та продажем вживаних дитячих речей — складно порозумітися німецькою на місцевих сайтах.
{% endstep %}

{% step %}
#### Дослідження проблеми (Біль)

Відчуваю брак регулярного кола спілкування для дитини. Малюку самотньо, він починає забувати рідну мову, а я не маю часу возити його на зустрічі на інший кінець міста.
{% endstep %}

{% step %}
#### Наслідки (Consequences)

Потребуємо компанії на вихідних та 1-2 рази в будні. Якщо не вирішити, дитина стане більш закритою, а я відчуватиму провину.
{% endstep %}

{% step %}
#### Як зараз вирішують (Current Solutions)

Використовую Vinted та Kleinanzeigen. У Telegram-групах формату «Продам» суцільний комерційний спам від магазинів, знайти речі від реальних мам неможливо.
{% endstep %}

{% step %}
#### Критичність (Urgency / Safety)

Хочу бачити бейджі перевірки профілю, щоб безпечно купувати речі чи обмінюватися ними з сусідками.
{% endstep %}

{% step %}
#### Бар'єри та вимоги (Barriers)

Обов'язково скористалася б локальним маркетплейсом для обміну речами та пошуком друзів для сина. З радістю подивлюся прототип.
{% endstep %}
