# Stage 1

Кожен із членів команди має заповнити по одній таблиці з **питаннями для Vision Statement**.

Впишіть свої прізвище та ім’я, далі індивідуально подумайте щодо продукту, який пропонується в розробку.

Це може бути:

* ваш власний продукт;
* продукт із вашого досвіду, з яким ви вже працювали;
* уявлений продукт.

Коротко опишіть продукт, щоб було зрозуміло, що він собою являє. Додайте посилання, якщо продукт існує.

Вам потрібно визначити «чому», що стоїть за вашим продуктом, причину його існування на ринку. Ви маєте запитати себе: «Чому я створюю саме цей продукт? Яка мета його створення? Які позитивні зміни це принесе?» (див. приклад).
