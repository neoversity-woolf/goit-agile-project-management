# Stage 3

1. Складіть профіль споживача
2. Складіть частину «Ціннісна пропозиція»
3. Оцініть відповідність між вашою цінністю та потребами й бажаннями клієнта
4. Спираючись на створену Value Proposition Canvas, сформулюйте Value Proposition Statement для свого продукту. Для полегшення завдання можете дотримуватися одного з 5 шаблонів та прикладів до них
5. Сформулюйте Unique Selling Proposition для свого продукту
6. Переконайтеся, що Product Vision, Value Proposition Statement та Unique Selling Proposition не суперечать один одному
