# Опис завдання

Завдання складається з двох етапів:

* Етап 1 — формування Customer Journey Map, опис ідей у вигляді елементів беклогу продукту у форматі User Story, проведення скорингу беклогу та визначення User Stories, які увійдуть у MVP.
* Етап 2 — побудова воронки AARRR для свого продукту, визначення основних метрик на кожному етапі, визначення власних варіантів для North Star Metric та Inputs.
